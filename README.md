# 3D陀螺對線

手機優先嘅網頁 3D 陀螺對戰遊戲。Bill Chiu 開發。

## 點樣玩

1. 喺主頁揀「1 VS 1」。
2. 喺盤上面拖動，揀陀螺衝去邊個方向。
3. 按住發射器拉柄，由螢幕最左邊一直拉去最右邊。拉得越快，轉速越高。
4. 對戰時拖動畫面控制陀螺，撳技能掣用金屬刃嘅主動技能。

## 計分

| 結果 | 分數 |
|---|---|
| 對手爆裂 | 2 |
| 對手入出場窿並停轉 | 2 |
| 對手入極限區並停轉 | 3 |
| 對手停轉 | 1 |

## 陀螺零件

- **金屬刃**：9 款角色金屬刃，每款有自己嘅主動技能。
- **固鎖 z-y**：z 係尖角數量（1 至 9），y 係高度（50 至 80 mm）。尖角越少，攻擊同復活力越高；尖角越多，血同防禦越高；單數尖角唔平衡。越高越易爆。
- **軸心**：平底、尖底、球底、加速底、鋼針底。

## 注意

- 呢個版本可以玩 1 VS 1、陀螺工房同商店。
- 連線對戰只可以喺 claude.ai 版本玩（要登入）。
- 進度存喺你部手機或者電腦嘅瀏覽器入面。
